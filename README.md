
# EEEP Clemente Olintho Távora Arruda
### Site Institucional

---

## Sobre o projeto

O **Site Institucional da EEEP Clemente Olintho Távora Arruda** é um projeto de desenvolvimento web que tem como finalidade criar uma plataforma digital para apresentar a instituição, divulgar suas atividades e facilitar o acesso às informações da comunidade escolar.

A proposta é desenvolver um ambiente virtual moderno, organizado, acessível e responsivo, que represente a identidade da escola e reúna seus principais conteúdos em um único espaço.

O projeto está sendo desenvolvido utilizando tecnologias fundamentais do desenvolvimento web: HTML5, CSS3 e JavaScript.

## Objetivos

- Fortalecer a presença digital da instituição.
- Apresentar a história e a identidade da escola.
- Divulgar os cursos técnicos ofertados.
- Disponibilizar notícias, eventos e comunicados.
- Facilitar o acesso às informações institucionais.
- Reunir links e serviços importantes para estudantes, professores e visitantes.
- Proporcionar uma navegação simples e intuitiva.

## Seções do site

### 1. Página inicial
Apresentação da instituição, com informações introdutórias e acesso às principais áreas do site.
### 2. Cursos técnicos
Área destinada à divulgação dos cursos ofertados pela escola:

- Administração;
- Logística;
- Contabilidade;
- Informática.

### 3. Sobre a escola
Espaço destinado à apresentação da história, missão, valores e identidade institucional.
### 4. Notícias e comunicados
Área planejada para divulgar acontecimentos, projetos, eventos e avisos importantes da comunidade escolar.
### 5. Contato
Página destinada à disponibilização dos canais oficiais de comunicação da instituição.
### 6. Acesso ao AVA
Atalho para o Ambiente Virtual de Aprendizagem utilizado pela comunidade escolar.

## Identidade visual

O projeto busca manter uma identidade visual institucional, priorizando:
- Verde: cor principal da identidade visual.
- Branco: clareza e organização.
- Tons neutros: equilíbrio visual e legibilidade.

A interface busca apresentar uma aparência moderna, limpa e consistente em todas as páginas.

## Como executar o projeto

Como o projeto utiliza tecnologias front-end, não é necessário instalar dependências para visualizar a versão inicial.

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador.
5. Para facilitar o desenvolvimento, recomenda-se utilizar o Visual Studio Code com a extensão Live Server.

### Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd PROJETO-ESCOLA
```

Depois, abra o arquivo `index.html` no navegador ou utilize o Live Server.

## Organização e manutenção

Para manter o projeto organizado:

- Utilize nomes de arquivos claros e padronizados.
- Armazene imagens na pasta `assets/images`.
- Armazene ícones na pasta `assets/icons`.
- Separe os arquivos JavaScript na pasta `js`.
- Organize as páginas internas na pasta `pages`.
- Evite duplicação de código.
- Mantenha os caminhos dos arquivos atualizados.
